Workspace Structure

Projects are the top-level workspaces. Each project can contain multiple Boards and members.

Boards are where tasks live. Each board contains Lists, and each list contains Cards (tasks).

Access Types
  • Project roles apply across the entire project (all boards inside it).
  • Board roles apply only to specific boards you are assigned to.

Account & Access Requirements

To be added to a Project or a Board, a user must first be registered in the system.

Important: Invitations are tied to the user’s registered email. If the email is not registered, the user cannot be added until they create an account.

Shared Permissions (Daily Work)

View boards, lists, and cards Create cards Edit card title / priority Move cards between lists Reorder cards within a list Update card content (description) Set due date & status Add / delete comments Assign / remove card members Reorder lists

Roles & Responsibilities

👑 Project Owner

Full control of the project and everything inside it.

  • Create, edit, and delete boards
  • Update and delete the project
  • Manage project members (add/remove/change roles)
  • Manage board members (add/remove/change roles)
  • Rename & delete lists
  • Delete cards

🛠 Project Admin

Manages boards and members, but cannot delete the whole project.

  • Create and edit boards
  • Manage board members (add/remove/change roles)
  • Rename & delete lists
  • Delete cards
  • Cannot delete boards or projects
  • Cannot manage project membership

👤 Project Member

Works across project boards, with limited management permissions.

  • Create lists
  • Create and edit cards
  • Move and reorder cards
  • Add/delete comments
  • Cannot rename/delete lists
  • Cannot manage members

⚙️ Board Admin

Manages board structure and content within an assigned board.

  • Create lists
  • Rename & delete lists
  • Create and manage cards
  • Delete cards
  • Cannot delete the board
  • Cannot add board members (project roles handle this)

🧩 Board Member

Works on tasks in an assigned board.

  • Create lists
  • Create and manage cards
  • Move and reorder cards
  • Add/delete comments
  • Cannot rename/delete lists
  • Cannot delete cards

Notes

  • Project roles affect all boards under the project.
  • Board roles affect only the specific board you’re assigned to.
  • If you can’t access a board, ask a Project Owner/Admin to add you.
