Projects & Boards Overview

Projects are the main workspaces that group together multiple boards and members.

Boards are task spaces within projects, containing Lists and Cards for organizing work.

Access Types
  • Project Roles → access to all boards within a project.
  • Board Roles → access to only specific assigned boards.

Common Abilities for All Roles

  • View all lists and cards they have access to
  • Create, edit, and delete lists
  • Create, edit, and delete cards (tasks)
  • Move and reorder lists and cards
  • Add and delete comments on cards

Project Roles

👑 Project Owner

Has complete control of the project and everything inside it.

  • Manage project details (name, category, description)
  • Create, edit, and delete boards
  • Add or remove project members
  • Change project member roles
  • Add or remove board members
  • Full access to all lists, cards, and comments

🛠 Project Admin

Helps manage the project and all boards but has limited project-level permissions.

  • Access and manage all boards within the project
  • Edit board names and settings
  • Add or remove board members
  • Cannot delete the project or edit project details
  • Full access to all lists, cards, and comments

👤 Project Member

Can work on all boards within the project but cannot manage members or settings.

  • Access all boards under the project
  • Work freely with lists and cards
  • Cannot add, remove, or manage board members
  • Cannot edit project or board settings

Board Roles

Board roles apply only to users directly assigned to a board. These users can’t access other project boards.

📌 Board Owner

Full control of the assigned board.

  • Edit board name and settings
  • Add or remove board members
  • Manage lists, cards, and comments

⚙️ Board Admin

Can manage all board content but not members or settings.

  • Create, edit, and delete lists and cards
  • Move lists and cards
  • Add and delete comments
  • Cannot manage board members
  • Cannot delete or edit board settings

🧩 Board Member

Can work on tasks within the board but not manage settings or members.

  • View board content
  • Create, edit, and delete lists and cards
  • Move lists and cards
  • Add and delete comments
  • Cannot manage board members or board settings

Additional Notes

  • All users share basic abilities to create, update, and move lists and cards.
  • Project roles apply to all boards in the project; board roles apply only to assigned boards.
  • Only owners can delete entire projects or boards.
