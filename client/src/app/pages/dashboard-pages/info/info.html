About Projects and Boards

Projects are the main workspaces where your teams organize all boards. Each project can contain multiple boards, and each board represents a specific workflow or task space (for example: Design Board or Development Board).

Project Roles & Permissions

👑 Project Owner

Has full control over the entire project. Can create, edit, delete projects, boards, and members. The owner can also manage roles and permissions for all users.

🛠 Project Admin

Has access to all boards under the project. Can add or remove members from boards but cannot delete the project or manage project-wide settings.

👤 Project Member

Has limited access to project content. Can view all boards and create or delete cards, but cannot add members or edit/delete the project.

Board Roles & Permissions

⚙️ Board Admin

Can add or remove members and update the board name, but cannot delete the board itself.

🗂 Board Member

Can create, edit, and delete cards within the board lists, but cannot modify board settings or member access.

Additional Notes

  • Only project owners can assign or change user roles.
  • Board-level roles are managed independently from project roles.
  • Members removed from a project automatically lose access to all boards inside it.
