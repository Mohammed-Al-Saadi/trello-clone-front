About Projects and Boards

Projects are the main workspaces where your teams organize all boards. Each project can contain multiple boards, and each board represents a specific workflow (for example: Design Board or Development Board).

Boards contain Lists (columns) and Cards (tasks). Your access depends on your role inside the project.

Project Roles & Permissions

👑 Project Owner

Has full control of the project and everything inside it.

  • Project: view, update, delete
  • Members: add/remove members, view member list, update member roles
  • Boards: create, view, update, delete
  • Lists: create, update, delete
  • Cards: create, view, update, delete

🛠 Project Admin

Can manage the project content and members, but cannot delete the project.

  • Project: view, update (cannot delete)
  • Members: add/remove members, view member list, update member roles
  • Boards: create, view, update, delete
  • Lists: create, update, delete (only owner/admin)
  • Cards: create, view, update, delete

👤 Project Member

Can work inside boards (lists + cards) but cannot manage project members or project settings.

  • Project: view project details
  • Members: no access to project member list / add / remove / update roles
  • Boards: view board details (cannot create/update/delete boards)
  • Lists: create and update list titles (cannot delete lists)
  • Cards: create, view, update, delete

Note: Members can fully work on tasks (cards) and organize lists, but cannot manage who joins the project or delete lists.

Board Roles & Permissions

Board roles apply inside a single board. A user must first have access to the project to access boards. Board roles then define what the user can do inside that board.

📌 Board Owner

Full control of the board.

  • Board: update board name/settings, manage everything
  • Members: add/remove board members, change board roles
  • Lists: create, update, delete lists
  • Cards: create, view, update, delete cards

⚙️ Board Admin

Can manage board content and members, but cannot delete the board.

  • Board: update board name (and board settings if allowed)
  • Members: add/remove board members (cannot remove board owner)
  • Lists: create and update lists (delete lists only if allowed)
  • Cards: create, view, update, delete cards

Note: Board Admin can manage members inside the board, but they should not be able to delete the board.

🧩 Board Member

Works on tasks inside the board only.

  • Board: view board
  • Members: cannot add/remove members
  • Lists: create lists and update list titles (if allowed), cannot delete lists
  • Cards: create, view, update, delete cards
