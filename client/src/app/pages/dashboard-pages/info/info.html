Projects & Boards

Projects are workspaces that contain multiple boards and members.

Boards organize your workflow using Lists (columns) and Cards (tasks).

Access Levels
  • Project Roles → Grant access to the entire project and all its boards.
  • Board Roles → Limit access to a single assigned board only.

Project Roles & Permissions

👑 Project Owner

Has full control over the project and everything inside it.

  • Manage project details (name, description, category)
  • Add, edit, and delete boards
  • Add and remove project members
  • Change project member roles
  • Add and remove board members
  • Manage lists (add, edit, delete)
  • Manage cards and tasks (add, edit, delete, move)
  • Manage board categories and names

🛠 Project Admin

Can manage boards, lists, and cards in all project boards, but cannot delete or rename the project.

  • Access all boards inside the project
  • Add and edit boards (cannot delete project)
  • Add members to boards (cannot add project members)
  • Manage lists (add, edit, delete)
  • Manage cards and tasks (add, edit, delete, move)
  • View and collaborate on all boards

👤 Project Member

Can work on all boards inside the project but cannot manage members or project settings.

  • Access all boards inside the project
  • View and collaborate on lists and cards
  • Add, edit, and delete cards and tasks
  • Add and edit lists (cannot delete lists if restricted)
  • View project details

Board Roles & Permissions

Board roles apply only to the board the user is assigned to. These roles are independent from project roles.

📋 Board Owner

Has full access to manage everything inside their board.

  • Manage board details (name, settings, category)
  • Delete board if needed
  • Add, edit, and delete lists
  • Add, edit, and delete cards and tasks

⚙️ Board Admin

Can manage board content but cannot manage members or delete the board.

  • Add, edit, and delete lists
  • Add, edit, and delete cards and tasks
  • Update board name or category (cannot delete)

🧩 Board Member

Can work inside the board but has limited permissions.

  • View board content
  • Add, edit, and delete cards and tasks
  • Add and edit lists (cannot delete lists)
  • Cannot add or remove board members
  • Cannot delete or rename the board

Notes

  • All roles can manage cards and tasks according to their assigned board or project role.
  • Project Owners have the highest access across all boards and members.
  • Board roles apply only to the assigned board and do not grant access to the entire project.
  • Project roles automatically include access to all boards within the project.
